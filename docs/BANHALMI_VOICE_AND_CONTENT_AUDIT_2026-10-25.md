## 1. Identity

**Norbert Bánhalmi is a photographer, visual artist and visual positioning partner.** In commissioned professional work, photography is the instrument; the outcome is an appropriate, credible visual presence. In artistic work, the photograph is an autonomous work, not a marketing deliverable. Do not blur these two roles.

Internal positioning statement: **A fénykép az eszköz. A munka a stratégiai vizuális pozicionálás.** This is an approved strategic formulation, not necessarily the best visible H1 on every page.

One-sentence public explanation: **Olyan portrékat és vizuális anyagokat készítek, amelyek pontosan illeszkednek ahhoz, ahogyan Önnek vagy a szervezetének meg kell jelennie.**

Short alternative: **Portréfotózás és tudatos vizuális megjelenés vezetőknek, szakembereknek és alkotóknak.**

Do not claim measurable business outcomes, guaranteed conversions or particular celebrity/brand clients without direct evidence.

## 2. Voice profile

- **Courteous, not ceremonial:** HU website uses consistent formal address (Ön/Önnek), respectful salutations in messages. No artificial distance.
- **Human, not salesy:** thanks for trust; recognize individual circumstances; avoid self-congratulation.
- **Direct, not abrupt:** one idea per sentence; concrete next steps, deliverables and expectations.
- **Confident, not boastful:** show work, method and evidence rather than declaring excellence.
- **Collaborative, not submissive:** calmly state limits and requirements; suggest a workable alternative.
- **Restrained, not cold:** measured warmth; no excessive exclamation marks, emojis or inflated adjectives.
- **Context-aware:** formal for institutions, more personal with established contacts; the public site remains consistently formal in HU.

### Preferred vocabulary

`portré`, `megjelenés`, `személyes arculat`, `hiteles`, `természetes`, `következetes`, `válogatott munkák`, `közös egyeztetés`, `felhasználás`, `képek`, `fényképek`, `helyzet`, `cél`, `környezet`, `személyre szabott`, `időtálló`, `vizuális pozicionálás` (only where explained).

### Sentence patterns

## 4. Two distinct brand voices

### Professional — norbertbanhalmi.com

Voice: clear, restrained, empathetic, practical. Structure: **who it serves → problem → what changes → method → work examples → next step**. First person is suitable in personal introduction and selected service copy. Avoid agency-style `mi` if Norbert is the actual service provider. Keep copy scannable: H1 one clear subject, H2 one distinct idea, body two to four concise sentences per block. Explain abstract terms on first mention.

### ART — banhalmi.art

Voice: observational, reflective, exact, unhurried. Structure: **work/project → artistic question → medium and context → images → provenance / exhibitions → contact**. No hard sell, no invented interpretation, no commercial service catalogue. `Művészi akt` is an art category, not an adult-service proposition. Maintain consent, image rights and age-appropriate presentation. Project descriptions should distinguish documented artist statements from editorial interpretation.

## 7. Comparison protocol — mandatory before any rewrite

Cursor must generate `content-audit-before-after.csv` for **every** indexable route × `hu`, `en`, `de-AT`:

`repo, route, locale, source_file, current_h1, proposed_h1, current_h2s, proposed_h2s, current_meta_description, proposed_meta_description, deviation_category, reason, evidence, priority, status`

Deviations to flag:
1. Superlatives and empty luxury claims without proof.
2. H1 describes an abstraction but not the service / project.
3. H2 repeats H1 or is a generic slogan.
4. Third-person corporate marketing where a personal voice is more credible.
5. Informal HU website address, inconsistent `Ön` register.
6. Excessively long text that interrupts the decision path.
7. Service / art intent leakage across domains.
8. Unverified claims, invented references or outcomes.
9. Missing geographical/service clarity where relevant.
10. Title, H1 and meta description duplicate one another without distinct purpose.

Severity: P0 factual/legal/intent misrepresentation; P1 primary page comprehension, voice or metadata; P2 polish. Report exact original text, file path and line number. If a value is dynamic, follow the code path to its source. If unavailable, mark `NOT VERIFIED`, never fabricate.

## 9. Editorial acceptance criteria

- A first-time visitor can understand **who, for whom, what and next step** within approximately five seconds on each service landing page.
- No marketing claim is stronger than its available evidence.
- Each H1 names the actual page intent; each H2 adds information.
- Every page has one primary H1; metadata is unique where appropriate.
- Every Hungarian visitor-facing service text consistently uses polite formal address.
- Professional and ART are distinct in commercial intent, terminology and structured data.
- All changes are traceable to an exact route, locale and source file.
- All actual current-versus-proposed comparisons are produced from code or rendered output, not assumed from this brief.
