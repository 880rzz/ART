# SVT-inspired pendulum system — implementation notes

The public descriptions of Spiritual Response Therapy/Technique describe a workflow using pendulum charts, preparation to work, systematic questioning, clearing, a mop-up step, healing/integration and final verification. Public sources do not provide a complete authoritative table set, and commercial/course tables may be protected material. Therefore this build implements an original, SVT-inspired self-reflection system rather than copying an official proprietary chart pack.

## Implemented chart sequence
0. Preparation to work
1. Permission and readiness
2. Primary program / All is well
3. Theme
4. Source
5. Time layer
6. Affected life area
7. Intensity
8. Correction / release method
9. Supportive replacement quality
10. Is there another program?
11. Mop-up
12. Integration / healing
13. Accuracy and completeness verification

“All is well” is exclusive and immediately closes the session.
